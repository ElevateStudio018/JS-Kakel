# JS Kakel & Sten AB – ny hemsida

Statisk enkelsida, ingen byggprocess. Öppna `site/index.html` i en webbläsare eller ladda upp mappen `site/` till valfritt webbhotell.

- `site/` – hemsidan (HTML, CSS, optimerade bilder)
- `scrape/` – skrapat underlag från gamla sajten, se `scrape/INFO.md`

## Att stämma av med kunden

- **Bilder:** inspirationsbilderna är leverantörsbilder från gamla sajten. Byt helst mot foton från egna jobb (badrum, kök, uteplatser), särskilt hero-bilden.
- **Formulär:** öppnar besökarens e-postprogram (mailto). För ett riktigt formulär, koppla till t.ex. Formspree eller webbhotellets formulärtjänst.
- **Texter att bekräfta:** att BKR-behörigheten fortfarande gäller, att arbetsområdet är Kungälv/Göteborg, att det är okej att skriva i jag-form, och att listan över tjänster stämmer.
